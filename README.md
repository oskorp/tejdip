# tejdip

Interactive Marathi engagement invitation (साखरपुडा) for **Tejas Jadhav & Dipali Bhangrath**, 19 December 2026.

Open `index.html` in a browser. Tap the seal to open the doors.

- Opening wada doors, petal showers, rings that join on scroll
- Rangoli countdown, programme, blessings
- Raag Bhupali music (bansuri, tanpura, tabla in Keherwa) generated in the browser
